# K-Play Korean 🇰🇷

> Learn Korean through K-drama and K-pop — not textbooks.

**Target**: US English-speaking learners, 18–30, K-drama/K-pop fans  
**Stack**: React 18 + Vite + TypeScript + Tailwind CSS  
**Deploy**: Cloudflare Pages

## Learning Science Built In

- **Active Recall** — try to remember before the answer is revealed
- **Spaced Repetition** (SM-2) — reviews scheduled by your performance
- **Phrase Chunks** — real-life sentence patterns, not isolated words
- **Interleaving** — micro test mixes all learned words
- **Micro Test** — triggered every 3 bites completed

## Getting Started

```bash
npm install
npm run dev
```

## Deploy to Cloudflare Pages

- Build command: `npm run build`
- Output directory: `dist`
- Node version: 18

## Content

Weekly theme splits:
- **Weekday** — light everyday expressions (대박, 화이팅, 어머)
- **Weekend** — party & social expressions (원샷, 야, 대박이다)

Drama titles always shown as: 한국어 제목 (International Title)
